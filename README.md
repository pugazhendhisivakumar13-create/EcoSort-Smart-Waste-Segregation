# EcoSort – Smart Waste Segregation System

**Team Name:** SortTech

**Theme:** Environment & Sustainability

## Problem Statement
Improper waste segregation causes pollution, increases landfill waste, and makes recycling difficult.

## Solution
EcoSort uses sensors, an Arduino microcontroller, a stepper motor, and a servo motor to automate a waste-sorting mechanism.

## Hardware Requirements
- Arduino Uno
- IR sensor
- Proximity sensor
- Moisture sensor
- Stepper motor
- Servo motor
- Buzzer
- Connecting wires and power supply

## Software Requirements
- Arduino IDE
- CheapStepper library
- Servo library

## Setup Instructions
1. Install the Arduino IDE.
2. Install the required libraries.
3. Connect the components according to the pin configuration in the code.
4. Open `EcoSort.ino`.
5. Select the correct board and port.
6. Upload the code and open Serial Monitor at 9600 baud.

## Environment Variables
Not required for this Arduino prototype.

## Future Improvements
Add IoT-based bin-level monitoring, improved waste classification, and recycling analytics.
